# LOVE COLOR · 두 사람의 색 견본집

두 사람을 상징하는 색 하나씩, 각자의 사랑을 상징하는 색 하나씩을 OOC나 직접 입력으로 뽑아 한 권의 색 견본집으로 펼쳐 보는 결과 뷰어 — 빌드 없는 HTML/CSS/JavaScript.

**https://yuuuulll35.github.io/love-color/**

## 사용법

맨 위 **01 페어 이름**은 견본 카드와 첫 화면에 들어가는 이름이다(선택, 16자). 비우면 두 캐릭터 이름이 들어간다. **02 네 가지 색**에서 입력 방법을 탭으로 고른다.

**OOC 입력**

1. **OOC 복사** → 채팅에 보내기 → 받은 답을 복사하고 **답 붙여넣기**.
2. 답이 확인되면 요약과 **다시 넣기 / 지우기**가 나오고, **02-1 색상 보정**이 열린다. 견본을 누르거나 코드를 적어 네 색을 고칠 수 있고, 고친 색은 **수정됨**으로 표시되며 **원래 색으로**로 되돌린다.

브라우저가 클립보드 읽기를 막으면 입력 칸이 열린다. **직접 붙여넣기**로도 열 수 있고, **OOC 내용 보기**로 보낼 문장을 미리 볼 수 있다.

**직접 입력**

1. **02-1 캐릭터명**: 두 캐릭터의 이름(각 12자).
2. **02-2 색상 선택**: 각자의 상징색과 사랑색을 고르고, 원하면 색 이름(12자)을 붙인다. **혼합색 비율** 막대로 두 사랑색이 섞이는 양을 정한다. **?**를 누르면 무엇이 섞이는지 설명이 뜬다.

3. **02-3 한 줄 문구**(선택, 40자): 결과 첫 화면에 놓이는 문장.

직접 입력에는 AI 답이 없으므로, 비워 둔 문구는 색에서 자동으로 만든다(`js/lexicon.js` 문구 표 + `js/describe.js`). 색마다 문장을 저장하지 않고 색의 속성(색상 계열 12개 + 무채색, 톤 8단계, 무채색 명도 5단계, 두 사랑색의 관계 6종, 혼합 비율)별 조각을 조합하므로 어떤 색 조합에도 문구가 나온다. 같은 색이면 항상 같은 문구가 나온다.

| 문구 | 만드는 방식 |
|---|---|
| 색 이름 | 톤 수식어 + 계열·톤별 이름. 톤은 선명 / 맑음 / 은은 / 옅음 / 흐림(회색빛) / 짙음 / 저묾 / 깊은 밤 8단계이고, 계열마다 맑은 색·옅은 색·회색빛·짙은 색 이름을 따로 둔다(예: 선명한 쪽빛, 옅은 물망초빛, 흐린 회청빛, 저문 감청빛). 무채색은 백자빛·은빛·잿빛·숯빛·먹빛. 입력칸에 회색으로 미리 보이고, 적으면 적은 이름을 쓴다 |
| 이유 | 계열 문장(상징색·사랑색 따로) + 명도·채도 문장 |
| 키워드 | 상징색 계열의 단어 묶음에서 3개 |
| 질감 | 사랑색의 명도·채도로 결정 |
| 혼합색 이름·설명 | 혼합색의 수식어 + 혼합색 계열 이름, 두 사랑색 관계별 문장 |
| 비율 설명 | 반반 / 조금 기움 / 많이 기움 |
| 한 줄 문구 | 두 사랑색 관계별 문장. 입력칸에 회색으로 미리 보인다 |

**견본집 펼치기**는 준비가 안 됐을 때 흐리게 보이고, 누르면 빠진 것(답 없음, 이름 없음, 같은 이름)을 알려 준다. 입력칸은 앞 공백·연속 공백·제어문자를 정리하고 글자 수를 표시한다.

탭을 바꾸면 두 탭에 입력한 내용(답, 고친 색, 캐릭터명, 고른 색, 혼합색 비율)이 모두 처음 상태로 비워진다. 두 탭이 함께 쓰는 페어 이름은 남는다.

결과 화면 끝의 **링크 복사**는 결과를 압축해 주소 뒤(`#r=…`)에 담은 링크를 복사한다. 서버에 저장하지 않으며, 받은 사람이 열면 같은 결과 화면이 바로 펼쳐진다(바꾼 혼합 비율 포함). 링크가 잘려 열 수 없으면 입력 화면으로 돌아가 안내한다.

페어 이름, 고른 탭, 답, 고친 색, 직접 입력한 내용은 이 브라우저(localStorage)에만 남아 다시 열면 그대로 이어진다. **예시로 보기**는 예시 답으로 바로 펼친다. 결과 화면 끝의 **테스트 다시하기**는 처음 화면으로 돌아간다.

## 견본집의 구성

배경은 옅은 색 하나의 그라데이션이다. 그 색은 스크롤 위치에 따라 지금 보는 장의 색으로 끊김 없이 이어지고, 그라데이션의 흐름도 스크롤에 맞춰 움직인다.

| 장 | 내용 |
|---|---|
| 첫 화면 | 흰 화면에 한 줄 문구(없으면 페어 이름)가 한 글자씩 떠오르고, 두 사랑색을 잇는 선이 그어진 뒤 그 아래에 스크롤 안내가 나온다. 스크롤하면 문구가 흐려지며 넘어간다 |
| 01 · 02 Symbol | 각자의 상징색 견본 칩과 같은 색상의 7단 명도 띠. HEX·RGB·CMYK·HSL·LC 코드·온도 |
| 03 Love Colors | 두 사랑색의 재질 견본. 답의 질감(매트·글로스·펄·벨벳·시어·메탈릭)에 따라 표면이 다르다 |
| 04 The Blend | 두 사랑색과 혼합색만으로 만든 그라데이션 화면, 혼합색 코드·이름·설명. 비율 막대로 다른 비율로 섞어 볼 수 있다 |
| 05 Palette | 다섯 색 막대(누르면 코드 복사), 색상 띠 위의 위치, 관계·색상 거리·대비·온도 |
| 06 Swatch Card | 견본 카드. 이미지 저장, 색 코드 일괄 복사, 테스트 다시하기 |

혼합색은 답에 코드를 받지 않고, 두 사랑색을 OKLab 색 공간에서 혼합 비율대로 섞어 계산한다. 그라데이션의 중간 색도 OKLab으로 계산해 탁해지지 않는다. 비율을 바꾸면 혼합색과 그 뒤의 화면 전체가 함께 바뀐다.

## OOC 답 형식

OOC는 한 번만 보낸다(약 1,420자, 롤플 채팅 입력창 1,500자 안). 다른 OOC 뷰어들과 같은 규격을 따른다: 머리말에 참고 범위(기존설정, 관계성, 성격, 성향, 말투, 서사, 캐릭터정보, 유저노트, 로어북)와 성인 명시, `[색 규칙]`·`[이름·문장 규칙]`, 코드블록 한 줄 한 항목 출력.

```text
대상: NPC 이름 / PC 이름
NPC 상징색: #RRGGBB · 색 이름 (English Name) · 이유
PC 상징색: #RRGGBB · 색 이름 (English Name) · 이유
NPC 사랑색: #RRGGBB · 색 이름 (English Name) · 이유
PC 사랑색: #RRGGBB · 색 이름 (English Name) · 이유
NPC 키워드: 명사, 명사, 명사
PC 키워드: 명사, 명사, 명사
NPC 질감: 질감 하나 · 근거
PC 질감: 질감 하나 · 근거
혼합 비율: NPC 00 : PC 00 · 근거
혼합색 이름: 색 이름 (English Name)
혼합색 설명: ~
한 줄: ~
```

| 항목 | 규칙 |
|---|---|
| 색 | #RRGGBB. 순수 원색·완전한 흰색/검은색은 피하고 네 색이 색상이나 밝기로 뚜렷이 다르게. 같은 사람의 상징색과 사랑색은 다르게. PC의 색은 PC가 실제로 한 말과 행동만 근거로 |
| 색 이름 | 한글 2~8자, 쪽빛·치자빛·도홧빛처럼 자연과 사물에서 온 이름 + 영문 2~3단어 |
| 이유 | 서사 속 실제 장면 근거 1~2문장, 60자 이내, 담담한 서술체 '~다.' |
| 키워드 | 2~4자 명사 3개 |
| 질감 | 매트 · 글로스 · 펄 · 벨벳 · 시어 · 메탈릭 중 하나 + 근거 1문장 30자 이내 |
| 혼합 비율 | 정수, 합 100, 더 깊이 마음을 쓰는 쪽이 크게 + 근거 1문장 30자 이내 |
| 혼합색 | 코드 없이 이름과 설명 2문장 100자 이내(코드는 사이트가 OKLab으로 계산) |
| 한 줄 | 결과 첫 화면 문장, 이름 없이 30자 이내 |

- 상징색 둘과 사랑색 둘, 네 색이 모두 있어야 열린다. 나머지 항목은 없으면 그 부분만 빠진다.
- 답이 글자 수 제한을 넘기면 읽을 때 문장 끝에서 다시 줄인다(이유 70자, 근거 40자, 설명 110자, 한 줄 40자).
- 줄 앞의 `NPC` / `PC` 대신 이름이 와도 읽고, 둘 다 없으면 나온 순서대로 NPC, PC로 본다.
- 코드블록, `**굵게**`, 목록 기호, `|` 구분, 소문자 색 코드, 앞뒤 잡문을 허용한다. OOC 문장을 그대로 붙여 넣으면 답을 복사하라고 안내한다.

## 실행

저장소 루트를 그대로 정적 호스팅(GitHub Pages 등)한다. ES 모듈을 쓰므로 `file://`로는 열리지 않는다.

```bash
python3 -m http.server 8000
```

## 구조

```
index.html     처음 화면
styles.css     디자인
js/app.js      입력 화면, 견본집 화면, 스크롤 연출, 카드 이미지
js/ooc.js      OOC 문장과 답 파서
js/color.js    OKLab 혼합, 명도 견본, 색 표기 변환
js/data.js     예시 답
js/lexicon.js  직접 입력용 문구 표
js/describe.js 색 속성 분류와 문구 조합
```

움직임 줄이기 설정에서는 배경 흐름과 스크롤 연출 없이 정지 화면으로 보여 준다.
